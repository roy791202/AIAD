    status

    categories
    normal
    Regenerate HTML from unchanged approved sources → CURRENT; embed ModuleSpec draft + trace rows.
    boundary
    Empty BDD/TDD on a node → row omitted or explicit empty arrays; missing optional work/design still projects.
    invalid
    Missing required source path in SOURCES list → generator fails closed; no partial READY claim.
    dependency_failure
    Unreadable approved packet → hard error; do not invent inventory.
    partial_failure
    One source unreadable → whole projection fails (no half-current HTML). If module.html write fails after module.json write, roll back JSON to prior pair.
    state
    Draft revision never auto-flips to approved; readiness of referenced packet stays NOT_READY.
    transaction
    Publish module.json + module.html as a pair: backup prior bytes, write both, on any write failure restore prior pair (no new-JSON/old-HTML).
    lifecycle
    Refresh after source edit → PROJECTION_STALE until regenerate; evidence_refs stay empty until owner EVID; plain pointers under evidence.
    regression
    SPEC sample_module_spec.json still loads; A fixture payload_sha256 unchanged; no production edits.
    intended_red
    Independent TDD may add a compile-able check that fails when bound_source_sha256 mismatches current bytes or when HTML lacks contracts/tests/scope/evidence/risk/diagrams.
