最小做法

  1. 暫存複製 UI；只在副本 IIFE 加測試出口，原 codec 函式逐段 hash 不變。用既有 Playwright＋Chrome 的真 DOMParser。
  2. 每案例新 browser context；IPC 只進記憶體 mock。Rust .sgendesign 走既有 parse／serialize API，臨時 probe／lock／target 全在暫存。
  3. 記錄接受／拒絕、型別／欄位差異、部分更新與錯誤；原始來源雜湊前後必須相同。未知期望保留 OPEN。

成本：0 正式檔案、0 既有測試修改、0 新依賴／Port／Manager。未來最多 3 個小型測試執行／樣本檔及衍生結果。

觀察與期望分開

CURRENT_STATIC：來源推測；MEASURED_CURRENT：執行後的實際結果；DESIRED_PENDING：版本嚴格性、未知欄位保存、型別保真、ID 修復、CDATA 修正與跨檔交易，皆不在這片自動核准。

驗收

  • AC1 Six format entry points each execute at least one currently supported success sample with actual JS/Rust production functions.
  • AC2 Applicable version/unknown/scalar/identity/CDATA/latefailure samples report actual outcomes; N/A requires reason.
  • AC3 Original byte hashes unchanged and all writes/calls isolated; full list of scratch paths supplied.
  • AC4 Existing-vs-desired matrix clearly flags OPEN semantics; no new preservation/rejection/rollback expectation auto-approved.
  • AC5 Harness compiler/bootstrap/lock failures classified separately from codec failure; no testskip counted PASS.
  • AC6 Result JSON->HTML contains per-case input/output/delta/error/source binding, runnable command and native UI/Agent NOT RUN.
  • AC7 After observations owner explicitly approves any normative expectations before RED/production fixes.
