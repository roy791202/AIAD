state_ownership

New explicit mapping request would become an additional authority for association only, not document content or product approval. This is architectural and currently unapproved. Prefer per-request immutable mapping bytes, no hidden sidecar autoload/canonical shadow state. Persistent storage/editor/export is a separate decision.

mutation_transaction

Read bytes→validate/hash→resolve all IDs→build temporary projection→freshness recheck→publish context-only. Any invalid mapping publishes diagnostics only, no partial resolved design bodies; product state/files unchanged.
