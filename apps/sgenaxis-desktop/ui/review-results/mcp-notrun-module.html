2. Assumptions

A real MCP implementation is not wired by DispatchHost::new. Existing StubMcpClient correctly returns ExecError::RealMcpDisabled without IO. DryRun remains explicit simulation and must remain usable. Feature real-mcp is not evidence of transport availability. Existing raw endpoint values may contain credentials, so rejection diagnostics must not interpolate them. Existing allowlist and forbidden-target guards retain precedence. The owner instruction approves this bounded recommendation; it does not approve wider lifecycle/Guard refactoring.
