## 1. Requirement Summary

Intent: Production MCP execution with no real transport must return a readable NOT RUN result, never simulated Live success. Inputs: existing MCP settings and StartRunArgs / StartImplementationArgs. Outputs: existing Result<StartRunResult,String>; success schemas remain unchanged. Primary module: agent-execution, MCP host composition. Scope: composition default and host error presentation only. Out of scope: real transport, new capabilities/ports/DTOs, Guard policy, lease policy, concurrency changes, other three improvement candidates. Owner authorization: 2026-10-26 派工執行 following the concrete MCP NOT RUN recommendation.

## 2. Assumptions

A real MCP implementation is not wired by DispatchHost::new. Existing StubMcpClient correctly returns ExecError::RealMcpDisabled without IO. DryRun remains explicit simulation and must remain usable. Feature real-mcp is not evidence of transport availability. Existing raw endpoint values may contain credentials, so rejection diagnostics must not interpolate them. Existing allowlist and forbidden-target guards retain precedence. The owner instruction approves this bounded recommendation; it does not approve wider lifecycle/Guard refactoring.

## 4. Architecture Plan

A1 System context: Tauri command clients invoke DispatchHost; EXEC routes to existing AgentPort adapters. A2 Hexagonal view and A3 dependency view appear below. A4 responsibilities: DispatchHost composes execution, checks host safety and binds accepted runs; AgentRouter selects provider; McpAgentAdapter enforces bindings/approval and produces chunks; McpClientPort abstracts transport; StubMcpClient rejects unavailable transport; Core owns board task state; WORK owns leases; EvidenceStore owns evidence. A5 input ports: existing start_run and start_implementation, AgentPort::start_run. A6 output port: existing McpClientPort connect/call_tool/disconnect. A7 driving adapters: existing Tauri commands and unit-test requests. A8 driven adapters: default StubMcpClient; FakeMcpClient only in explicit test fixture composition. A9 direction: UI → host → AgentPort/EXEC → McpClientPort abstraction; adapter implements port. A10 ownership: host owns composition/active-run handles, EXEC owns adapter session/queue, WORK owns lease, Core board owns task projection, evidence owns evidence. No ownership moves. A11 mutation: accepted EXEC start precedes lease binding and Core Running state. Failure must not bind lease, add/blue a task, publish active run, mark provider Running, advance successful FLOW or add evidence. Existing preflight checks and Guard pass bookkeeping remain unchanged. A12 transaction: validate target → idle/binding preflight → EXEC attempt → only on accepted start bind lease/update board/FLOW; unavailable transport exits before commit. Existing internal run-id allocation and Guard authorization state may change; neither constitutes accepted execution. A13 external boundary: no OS/network transport is introduced or contacted. A14 forbidden: UI → MCP direct route; Core/Domain → concrete MCP client; production FakeMcpClient default; any new public seam/schema; changing Guard, lease, persistence, BDD intent or public lifecycle contract. No circular dependency introduced.

Locked skeleton: dispatch.rs production imports replace FakeMcpClient with existing StubMcpClient and import existing ExecError if needed; DispatchHost::new MCP constructor argument becomes StubMcpClient; start_run_ungated maps MCP RealMcpDisabled only to a static readable NOT RUN diagnostic saying real MCP transport unavailable and suggesting DryRun; endpoint rejection uses static target-validation diagnostic without raw endpoint echo. All other errors retain current semantics. No change to error enum or EXEC SDK is required. Existing test module may explicitly construct AgentRouter with fake MCP inside a private fixture/helper or direct fixture assignment; do not add production injection API. Existing Live simulation test is preserved through explicit test injection, never claimed as real transport proof.

Contract C1: default host + activatable allowlisted MCP Live request cannot return Ok while no real transport exists. C2: failure String includes NOT RUN and readable unavailable reason. C3: failure cannot publish accepted Run/lease/Running task/provider/evidence success. C4: no settings secrets/raw endpoint credentials in new diagnostics. C5: empty / reserved :8788 / :8787 targets remain NOT RUN, never activated. C6: MCP DryRun and CLI behavior unchanged. C7: simulated Live adapter tests remain explicitly fake.
