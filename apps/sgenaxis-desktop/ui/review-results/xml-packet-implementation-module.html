責任與邊界

SPEC 僅處理 plain facts、全域引用驗證與確定性雜湊。Adapter 解析 XML 並拒絕 DTD／namespace 與超限輸入。HOST 驗證 lexical 路徑、讀取、擷取並重讀確認穩定。產品 SSOT、SPEC 核准與 EVID／GUARD 狀態皆不變。

Mutation：無。Transaction：讀取 → 驗證 → 投影 → 重讀比對 → 回傳。失敗不回傳部分封包。

契約、不變量與行為

模組 ID／slot ID 分離。節點、邊、port、module、slot ID 各自唯一。所有 graph endpoint、direction-specific port、dependency、membership 先驗證。只含選定 node/task body；internal／boundary edges 區分；UI 僅提供 context IDs，無法證明歸屬一律 unresolved。原始 hints／product_pass 不代表批准。

BDD、AC、TDD traceability 沿用獨立測試報告，不改測試意圖。
