Agent 執行順序

  1. 確認 primary module、ADR 與封包核准版本
  2. 建立對應 skeleton/test seams；不得改已核准語意
  3. 依 fixtures 與 TDD 設計寫可建置測試
  4. 執行測試並證明是指定缺失行為造成 RED
  5. 只在 allowed_scope 實作
  6. 執行相同測試達 GREEN；禁止弱化 assertions
  7. 跑模組與相關回歸，分類每個失敗
  8. 審查 diff/Contract/BDD/架構與驗收，更新 module.html；待人核准 commit
