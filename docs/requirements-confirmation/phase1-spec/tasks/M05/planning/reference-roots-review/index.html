M04 history projection + all document owners + M07 retained snapshots + in-flight transaction owner -> immutable completeness/revision projection -> M05 evaluator. M05 must not mutate providers.
state_ownership
Documents own references; M04 owns history; M07 owns recovery index; transaction owner owns temporary claims; M05 owns immutable asset identity/catalog only. Collected roots are derived projections, not an independent SSOT.
mutation_boundary
Evaluation is read-only. Later physical cleanup requires separately approved application transaction, complete root set and freshness fence. No direct UI-to-FS.
transaction_boundary
Collect complete roots -> evaluate bound candidate -> preview -> revalidate under approved exclusion -> delete only eligible owned bytes -> update catalog consistently. Missing seam means REPLAN_REQUIRED, not best-effort deletion.
candidate_first_slice
Pure evaluator only: immutable candidate identity/ownership plus root observations -> Retain(reasons), Ineligible(reason) or EligibleForCleanup. Eligibility is not deletion authority. No persistence/OS/clock/new output Port in this first slice.
