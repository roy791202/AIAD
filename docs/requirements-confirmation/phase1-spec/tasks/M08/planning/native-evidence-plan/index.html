architecture
hexagonal_view
Native operator/test driver -> declared UI/input boundaries -> module application/domain -> ports <- real Windows adapters. M08 observes outcomes and evidence; it does not bypass application safety.
dependency_view
M01 identity + M03 UI + M04 history + M05 material + M06 import + M07 recovery -> M08 bounded integration cases -> human review. M02 generated skeleton validation is separately gated, not implied by existing shell launch.
ownership
Product state stays with owning modules; fixture sandbox and evidence belong to the run. M08 health projection is not a new product SSOT.
mutation_boundary
Future operator acts only through authorized product operations on disposable inputs; direct test corruption is isolated fault injection. No real project/recovery deletion.
transaction_boundary
Artifact lock and fixture preparation -> run -> verify hashes/observable result -> preserve evidence -> cleanup only known disposable paths. Failure preserves diagnostic evidence and never changes external user data.
