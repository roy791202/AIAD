M08-HR05Capture must bind same run_id/PID/start/executable hash; screenshot alone is not executable/module proof.

M08-HR08Kill/fault tests terminate only exact run-owned PID with start-time/path/hash binding, never name-matched process or reused PID.
M08-HR09Artifact bytes/hash are locked before and after launch/move; source projects/materials compared before/after. Historical hash equality only validates identification, not eligibility.
M08-HR10Illustrative records and lower evidence layers may validate schema but never establish native/system PASS.
M08-HR11M08 aggregates read-only evidence, does not alter other modules/contracts/board zones or approve release.
