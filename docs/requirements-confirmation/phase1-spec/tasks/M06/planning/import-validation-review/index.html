architecture_proposal
hexagonal
UI/Test -> Tauri input -> DispatchHost -> HOST inspect/prepare/apply -> WORK pure import decision policy; HOST -> immutable source reader / decoder / safe staged transaction abstractions <- native/archive adapters.
module_dependencies
M01 identities + M04 document transaction/history + M05 material references -> M06 plan bound to exactly one target. M07 sees only completed or fully rolled-back document revision, never intermediate extraction.
ownership
Package bytes are immutable external input; target document owner remains SSOT. M06 plan/diff/validation report is a projection. Decoder cannot mutate documents or approve missing dependencies.
mutation
Inspect and prepare are read-only. Confirm authorizes only bound, previewed changes via target transaction. No UI-to-FS, direct package execution or hidden additional target.
transaction
Validated source snapshot -> complete temporary graph/reference plan -> explicit confirmation -> recheck source identity and target revision/safety -> stage owned bytes -> single-document coordinated commit/history -> receipt. Failure before commit preserves original; uncertain rollback keeps recovery evidence and blocks destructive follow-up. Exact transaction seam must be separately approved.
forbidden
  • Extract then validate
  • Name-based provenance guesses
  • Treat incomplete internal manifest as optional external dependency
  • Best-effort partial merge
  • Automatically execute scripts
  • Remove shared materials during Undo
recommended_defaults_not_approved
container
Keep existing ESS and legacy SGB1 reader contracts separate; BIN versioned manifest/container selection remains pending exact proposal, not auto-adopt ZIP.
external_dependency
External references carry explicit logical identity and pending-binding state; no automatic network download, mount or install.
bounds
Specify compressed bytes, expanded bytes, per-entry bytes, entry count, nesting and path length before parser Skeleton. Every cap needs max-1/max/max+1 fixtures. Numeric defaults are not invented as approved in this review.
first_slice
Pure decision/plan validation may be isolated without actual archive extraction, but exact types/signatures and file envelope must be approved before Skeleton.
