function
evaluate_import_preflight(report: &ImportValidationReport, context: &ImportPreflightContext, choice: IncompleteImportChoice) -> Result<ImportPreflightDecision, ImportPreflightError>
ImportValidationReport
source_digest:String; target_document_id:String; target_revision:u64; blockers:Vec<ImportBlocker>; missing_external_dependencies:Vec<String>; requires_other_document_change:bool
ImportPreflightContext
expected_source_digest:String; target_document_id:String; target_revision:u64
ImportBlocker
kind: UnsupportedFormat | UnsupportedVersion | Integrity | MissingInternalPayload | UnsafePath | AmbiguousEntry; subject:String; reason:String
IncompleteImportChoice
NotConfirmed | ExplicitlyAcceptMissingExternal
ImportPreflightDecision
Blocked{problems:Vec<ImportBlocker>} | NeedsDependencyConfirmation{missing:Vec<String>} | AllowedComplete | AllowedIncomplete{pending_bindings:Vec<String>, dependent_capabilities_blocked:bool}
ImportPreflightError
InvalidInput{field,reason} | StaleSource | StaleTarget | CrossDocumentChangeRequired
note
Nested blocker-kind enum and data DTOs only. HOST must create this report from actual verified bytes and validation, never from UI claims that a package is safe.
contracts
  • Validate nonempty bounded document/dependency/subject/reason strings and sha256 syntax. Same project scope is resolved by HOST before this boundary; report is not authorization.
  • All blocking format/version/integrity/internal-payload/path/ambiguity problems yield Blocked even if missing dependencies were explicitly accepted. No destructive action or execution exists in any outcome.
  • With no blockers, source digest and target document/revision must match context. Mismatch yields StaleSource/StaleTarget; never mix validated and newly reopened bytes.
  • With no blockers and matching context, requires_other_document_change returns CrossDocumentChangeRequired, preserving the one-target-document merge boundary.
  • With no blockers/cross-document change and no missing external dependency return AllowedComplete. With missing dependencies and NotConfirmed return NeedsDependencyConfirmation. Explicit acceptance returns AllowedIncomplete with exact pending IDs and dependent_capabilities_blocked=true.
  • Sort/deduplicate missing dependency IDs by byte order; blocker list sort by fixed kind order then subject/reason. Do not silently discard a blocking reason. Outputs are action values, not proof of full container validity, successful commit or authorization to execute.
