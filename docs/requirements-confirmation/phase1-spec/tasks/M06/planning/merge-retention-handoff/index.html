M06 · One Merge / Undo retention handoff

Yellow · PROPOSED_PENDING_OWNER · No Skeleton · DOCUMENT evidence only

One imported candidate is applied to one selected document by M04. M05 retains materials while roots are deferred. Undo restores content at a new revision. Formal Save remains separate.

Architecture and ownership

UI → M06 confirm orchestration → M04 sole DocumentOwner
                               → M05 material ports ← trusted issuer/provider adapters
M04 prepare → one commit (content + revision + history)
     lock released → publish Live / Undo / Redo roots → transfer-live
     roots fail → MergeAppliedRetentionDeferred; Import Held retained
explicit Undo + separate supplied Undo Held → owner undo → roots
     roots fail → UndoAppliedRetentionDeferred; both Held retained
