優先序與固定排序

  1. after ALL structural input validation, nonempty blockers -> Blocked before freshness or cross-document checks
  2. no blockers: source digest mismatch -> StaleSource
  3. then target ID or revision mismatch -> StaleTarget
  4. then requires_other_document_change -> CrossDocumentChangeRequired
  5. then empty missing list -> AllowedComplete regardless of choice
  6. then NotConfirmed -> NeedsDependencyConfirmation
  7. then ExplicitlyAcceptMissingExternal -> AllowedIncomplete with dependent_capabilities_blocked=true

Keep identical blockers, including exact duplicates. Sort stable by kind ordinal then subject UTF-8 bytes then reason UTF-8 bytes; every supplied valid reason remains represented. Missing dependency IDs alone sort/deduplicate by UTF-8 bytes. No locale sorting/casefold.

Actual Rust report/context revisions are u64 and enum values are closed. InvalidRevision/InvalidChoice/InvalidBlockerKind are reserved future decoding oracle errors, NOT constructible L0 Rust values. No serde/decoder added to this slice. Do not count impossible enum/out-of-range construction as executable domain RED.
