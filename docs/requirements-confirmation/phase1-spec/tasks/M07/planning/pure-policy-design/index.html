intent
Model the approved 60-second eligibility, no-overlap and captured-baseline completion rules without implementing clocks, capture, storage or asset pins.
confirmed
  • Every 60 seconds check content against last successfully saved recovery snapshot
  • No change: skip; no overlap; failed attempt retains baseline and retries next check
  • Do not capture intermediate clear/import/merge/Undo state
  • Changes during save remain pending after captured version succeeds
  • Formal-save and recovery baselines independent; formal save never clears retained snapshots
  • ProjectID/SessionID isolate recovery; original project path is location metadata
  • Recovery opens unsaved; removing history does not delete snapshots or files
architecture
hexagonal
Future timer/UI/test adapter -> HOST use case -> WORK transition_recovery pure state function; HOST will provide verified immutable capture/publication events through separately approved seams.
dependency_view
M04 stable immutable content + M05 material claims -> future HOST capture/store -> typed event -> M07 pure baseline state. Formal baseline remains owned by M04, not copied into this policy.
ownership
Per-project/session recovery policy owns only scheduling/attempt/recovery-baseline state. It does not own current document bytes, formal baseline or snapshot index.
mutation
Transition returns new state and action value; immutable caller input. No FS/global timer/crypto/environment dependency or direct document mutation.
transaction
Begin records captured identity; successful durable index acknowledgement advances only that captured fingerprint. Physical payload/index/material ownership transfer remains outside this slice and requires separate approved transaction.

precise_transition_proposal
  • Validate bounded IDs/fingerprints and project/session envelope first. No matching project/session means SessionMismatch without state change.
  • Check uses supplied monotonic elapsed milliseconds: now < last_check gives TimeRegressed; less than60000 elapsed gives NotDue. Use checked subtraction, not overflowing next-deadline addition.
  • At due Check with inflight or capture_requested, emit WaitInFlight and update last_check_ms to now; never queue missed periodic writes. At due Check with mutation in progress, emit DeferMutation and leave the elapsed deadline eligible so caller can recheck once stable.
  • At due stable Check, update last_check_ms to now. No current semantic fingerprint means InvalidInput rather than claiming an unchanged document. Equal to successful_fingerprint means SkipUnchanged; otherwise set capture_requested and emit RequestCapture. Missing successful baseline with existing unsaved content requests first capture.
  • BeginAttempt requires capture_requested and no inflight. The trusted capture seam supplies the actual latest stable captured revision/fingerprint/material digest, which may be newer than the original check observation. Record immutable capture; clear capture_requested; emit AttemptRegistered.
  • Complete must match the inflight attempt ID in the same session. Published means durable verified payload/material/index publication, supplied only by trusted HOST; advance successful_fingerprint to inflight.captured_fingerprint, never to current document fingerprint. Clear inflight; emit BaselineAdvanced.
  • Failed completion clears inflight but keeps successful_fingerprint; emit RetryPending. Existing snapshots and staged assets are not deleted by any policy action. A later due Check compares current content again.
  • Duplicate/unknown attempt completion gives StaleAttempt. Close marks closed and clears unstarted capture request; it does not destroy retained data or reinterpret a completed save. A later completion in that closed session emits IgnoreClosedCompletion without advancing baseline; a different session remains SessionMismatch.
  • Formal save is intentionally not a policy event; it cannot reset the recovery fingerprint or delete snapshots. Ephemeral selection/playback cannot change current_fingerprint supplied by the approved semantic capture boundary.
