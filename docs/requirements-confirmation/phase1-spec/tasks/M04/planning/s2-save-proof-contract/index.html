契約

SP1 Capture
HOST retains immutable S1 snapshot, document/session IDs, owner generation, request UUID, canonical target/format and expected previous raw digest. All authority from server capture, never UI digest or writer fields.

SP2 Two digests
Encode capture once via future approved codec. Hash exact bytes as raw digest; retain captured content.semantic_digest separately. Different raw/semantic digests are valid and must not be equated.

SP3 Receipt
Verify all four receipt fields: target_path equals captured canonical target; previous_digest equals expected prior raw digest; committed_digest equals exact encoded-byte hash; transaction_id nonempty. Mismatch retains observed receipt/requested proof and performs no ACK, without claiming bytes unchanged.

SP4 ACK
After proof verification revalidate document/session IDs and owner generation, then call existing acknowledge_formal_save(captured revision,captured semantic digest). Never call ACK on another session with same revision.

SP5 Newer live revision
Saving captured R while same session is now R+1 ACKs R, not R+1. S1 computes dirty from live content. No forced clean flag, content rollback, edit/Undo entry or recovery-baseline update.

SP6 Deferred ACK
If receipt is verified but owner detached or S1 rejects ACK, return CommittedAckDeferred with proof/reason; no new commit/ACK retry onto replacement owner. Retain evidence for explicit reconciliation. Persistence success is not ordinary failed-unchanged.

SP7 Ordering
One save in-flight per document/session+target, application-owned request record. Same ID+capture replays retained result; different capture RequestConflict. No new global manager or IO-private journal.

SP8 IO failure
Preserve exact Busy/Conflict/InvalidPath/Storage/RecoveryRequired discriminants/fields; no ACK on Err. RecoveryRequired or receipt mismatch blocks further destructive calls only through separately approved R4 gate. Storage error is not invented rollback proof.

SP9 Ownership
Raw target baseline belongs to HOST binding; formal semantic baseline belongs to S1. Neither owns duplicate content. Formal save never invokes acknowledge_recovery_save; M07 remains separate.

SP10 Retention proposal
Runtime-only request records, no time eviction; at128 session/1024 runtime keys refuse new reservation before IO. Existing replay remains available. No across-restart exactly-once guarantee, new dedupe file or persistence schema.
