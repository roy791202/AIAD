Inspection／DocumentContent 界線

Inspection is NOT DocumentContent mutation authority. Only trusted application validator may convert resolved inspection to existing S1 DocumentContent; never fill asset_refs=[] by default merely because codec did not resolve material semantics.

契約

  • decode/inspect parse full source before replacing active state; no file/owner/Undo mutation
  • encode verifies canonical-payload format and recomputed semantic digest against supplied captured S1 content; mismatch is typed failure, not silently rebased digest
  • canonical_payload full represented document differs from raw source bytes; raw digest always hashes actual encoded output/IO receipt
  • Any change to semantic profile/exclusion list invalidates old semantic-baseline compatibility and requires explicit migration/replan; no hidden profile update
  • product_pass=true rejected wherever recognized format declares acceptance flag; no codec output becomes product PASS
  • Opaque unknown XML fields are preserved as data and mark derived UI projection unsupported/read-only when mapping unavailable; do not execute references or infer ownership
  • Cleared-document business policy is not invented inside generic serializer. Existing proposed cleared() placeholder must remain unsupported until exact section/content/asset semantics separately approved
  • Limits proposed16MiB input/output,depth64,100000 values/elements,1MiB decoded string; precise XML counting/error-order fixtures remain part of full R2 packet, not inherited from C1 approval automatically
