    architecture_mapping
    hexagonal
    UI/commands -> HOST document use case -> WORK DocumentSession; HOST -> codec/commit/material capabilities <- adapters. Existing selection EditSession remains separate.
    ownership
    DocumentSession owns content revision/history/baselines. HOST save orchestration and codec projections do not gain authority to replace current content. UI checkpoint cannot be a competing content SSOT.
    transaction
    Capture immutable stable R -> codec verified bytes -> actual durable commit -> acknowledge exactly R. Pending edit R+1 remains current. Failure before verified receipt does not acknowledge or clear either baseline.
    cross_module
    One-document merge feeds one compound history entry. M05 owns retained material identity; M07 index success determines recovery acknowledgement. M04 cannot delete material still retained by another root.
