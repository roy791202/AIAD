官方API依據

  • Rust Windows OpenOptionsExt.share_mode：官方說明share flags限制其他handle的讀/寫/刪，直到handle關閉；本方案使用獨立sidecar，避免把目標檔自己鎖到無法替換。
  • Rust fs::rename：可替換既有目標；跨檔案系統不成立；不能據此宣稱journal+target跨檔原子。
  • Rust fs::create_dir：已有目標或parent不存在會報錯；用於exclusive create，不用create_dir_all接受已存在目錄。

官方文件僅支持API語意；完整交易/回復保證是本提案需自行測試的責任，不能由API名稱推論PASS。
