問題與意圖

現有 HOST 型別未表示 UI 實際寫入的 gridSize/formSize/guides 與 node scope/uiExclusive，既有隔離實證有9條 path 在三節點文件中消失。此提案先確立可表示資料完整往返，不能表示者明確拒絕；避免直接加欄位後繼續悄悄丟失未知資料。

既有controlled HOST實證不是native UI、formal save或已批准TDD RED。原本baseline與props正對照能力保留，不重建。

不支援的資料不得靜默丟棄

16MiB、depth64、100000值、1MiB字串、4096字元數值token為此M03新建議，不因M01採納相近上限而自動生效。所有新增拒絕規則／error prefix都等Owner採納。

Editor／Viewer 權限與UI狀態方向

Editor選取不執行設定行為；明確內容編輯走應用層mutation。Viewer僅有與來源分離的mock state，不能呼叫任意Tauri dispatch、FS、AI、Git、plugin或外部程序。選取／播放／mock值不進內容Undo或復原快照。

stale revision/session、missing binding、ambiguous stable-ID、unsupported action/scope、missing material皆顯示不同結果；不猜名稱、不fallback執行。失敗refresh保留原投影並標stale，late completion不得覆蓋較新binding。

UI欄位：Editor／Viewer mode、唯讀binding與revision、refresh、cross-locate、明確狀態banner；mapping不明／stale時disable對應動作。這只是H2方向，未批准事件DTO／owner服務或runtime檔案實作。
