Architecture / ownership

External UI → Tauri command → M03 facade → M04 input → single S1 owner
M04 → C1 / M05 ports → adapters
M03 derived candidate ≠ authoritative content/history registry

Dependency and transaction

C1 prepare → immutable supported candidate
Native authorization → replay admission → generation/revision/unused check
M05 Candidate Held pin → M04 one atomic Edit → Live/Undo/Redo roots
AppliedRetentionDeferred = committed + retain Held, no rollback/retry
No formal IO / ACK. Unknown outcome = no inferred consumption, no resubmit.
