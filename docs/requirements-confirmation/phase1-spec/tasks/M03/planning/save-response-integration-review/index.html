SAVE-RF1

The command promises closed DTO/U64 range but both request fields inline only decimal syntax; max+1 is admitted by request schema and extracted checker. Existing 36 response tests do not exercise request schema.

Use a self-contained checked U64 string schema for both inline properties (or explicit bounded-string pattern), and request max/max+1/type/leading-zero witnesses under the full command root.

SAVE-RF2

22 IO rows cover CommitError variants/stages, but verified receipt + M05 root failure still has reason placeholder exact closed mapped deferred reason. Stage and reason enums admit combinations without an explicit per-stage matrix. No full MaterialError code/reason to save deferred mapping is present.

Enumerate reachable M05 code/reason per RootTransfer/SemanticAck state, typed stage-reason branches and unknown/unverified behavior, including transferred versus Held pin evidence. Add positive/negative complete responses for every distinct policy class.

SAVE-RF3

The lifecycle document checker derives Saved from matching raw receipt and condition==acked. It does not consume current document/session/generation, root transfer receipt, proof issuer/request binding or authorized delivery evidence. Two new adverse inputs still yield Saved/ACK1.

Replace result labels as primary oracle inputs with concrete current owner, verified issuer/root receipt and ACK result evidence. Define no-ACK/mismatch/deferred/delivery behavior and semantic counterexamples; do not call this production validation.
