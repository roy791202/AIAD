architecture_proposal
hexagonal
Editor/Viewer driving adapters -> approved commands -> HOST use case -> WORK immutable design/binding projections; HOST -> approved document/asset/verified-generation abstractions <- codecs/native adapters.
dependencies
M01 selected target + document owner + M02 verified generated snapshot + M05 material availability -> M03 projected Editor/Viewer state. M04/M07 observe content commits only, not ephemeral preview changes.
ownership
Document owner remains authoritative. Editor draft, selection and isolated mock Viewer state are explicit separate lifecycle projections, never writable mirrors of other documents.
mutation
Editor content edits use declared application mutation boundary. Selection/cross-location is view-only. Viewer uses mock-only allowlist and cannot call arbitrary dispatch commands.
transaction
Load/validate/bind immutable design revision -> build temporary preview projection -> replace Viewer projection only on success. Failure retains previous verified projection with stale label. No preview process writes source state.
forbidden
  • UI-to-filesystem
  • file URL bypass of verified generation
  • Executing imported code as preview behavior
  • Treating labels as identity
  • Replacing real document with preview mock state

component

role

controls
  • mode Editor/Viewer
  • current target and document revision (read-only)
  • refresh preview
  • cross-locate selected item
  • unsupported/stale/incomplete status banner
defaults
Editor is safe selection/edit mode; Viewer must be explicitly entered for mock interaction. Exact persisted mode default remains proposed.
disabled
Cross-locate disabled when mapping unresolved/ambiguous. Dependent mock action disabled if required capability/material missing. Refresh unavailable while source binding invalid.
errors
Report stale revision, unsupported action, invalid preview or missing material without claiming success.
empty
Explain no controls/no verified preview and provide only meaningful approved actions.
accessibility
Visible focus, keyboard-accessible mode/actions, announced status/error, no color-only capability distinction.
