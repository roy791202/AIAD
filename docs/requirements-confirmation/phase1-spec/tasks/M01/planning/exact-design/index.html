// Shared cross-module output capability, proposed in PORTS, not new Repository.
// May NOT be silently folded into FileSystemPort.write_atomic default behavior.
pub trait FileCommitPort: Send + Sync {
    fn create_directory_exclusive(&self, parent: &str, single_name: &str)
        -> Result<String, CommitError>;
    fn acquire_write(&self, path: &str) -> Result<Box<dyn FileWriteLease>, CommitError>;
}
pub trait FileWriteLease {
    fn read_current(&self) -> Result<Option<Vec<u8>>, CommitError>;
    fn replace_checked(&mut self, expected_digest: Option<&str>, bytes: &[u8])
        -> Result<CommitReceipt, CommitError>;
}
// OS-backed lock remains live until lease Drop; crash releases OS lock.
// Do NOT reclaim by a timestamp (board FileLock policy is not product guarantee).
// expected None = require missing; Some(hash) = require same prior raw bytes.
// replace_checked: stage/sync, preserve previous version, recheck under lock,
// replace single formal file; restore previous bytes before returning ordinary Err.
// If restoration itself fails: RecoveryRequired; retained versions + journal paths,
// block more destructive operations, never claim unchanged or successful.
// Post-commit notification/projection is not allowed to turn committed save into
// a false "failed, unchanged" result. Uncertain state is distinctly classified.
// Locks protect cooperating product writers; arbitrary external edits still need
// digest recheck and observed conflict handling, not a universal filesystem CAS.

操作序列
FirstSavevalidate name/draft/native parent binding → create_directory_exclusive → write definition and optional preference copy → bind only after required write success; partial retain owned artifacts, no recursive delete
ResumeSaveacquire project definition write lease → read digest → reject stale → encode pure draft → replace_checked → return exact saved revision
Finalizecurrent owned draft revision + prerequisites checked; unresolved returns DraftSavedMissingDecisions; generated artifacts only M02 separate operation
失敗階段可有變化處理驗收證據
decode/validate唯讀；尚未發出mutationInvalidInput/UnsupportedSchema拒絕，current/original/history不變malformed與未知欄位/版本fixtures
acquire/createOS lease或專屬新目錄ExistingTarget/Busy拒絕；新建不得刪既有目標檔案/空目錄/非空目錄、多writer原始bytes
prepare本次owned temp/不可變版本/pinsStorageFailure保留舊檔及session；新專案Partial列殘留stage/pin/sync每點注入失敗
publish單正式檔替換或一次domain swap回復before後才回普通failure；undo不入帳replace前後失敗及canonical/full byte對比
restore itself保留原有效版本/transaction紀錄RecoveryRequired且封鎖破壞性後續，不能宣稱原狀或成功restore失敗、不清理唯一preimage
postcommit projection提交已成立；畫面/通知是projection不把render錯誤轉成「未寫入」；顯示已提交版本/待更新UI成功commit後render失敗與重讀
late completion僅ack捕獲revision/session不能清掉R+1或別session的dirty；已關閉session不寫新projectsave中編輯、switch、close生命週期
Error語意
InvalidInput欄位/path/內容結構不合法，mutation前拒絕
UnsupportedSchema拒未知版本，不覆寫或靜默丟欄位
NotBound未綁專案/session，不碰FS
UnauthorizedCaller視窗非該session writer，不碰內容
ExistingTarget新建目標已存在，原檔/目錄不動
RevisionConflict期望revision或磁碟digest不符，重新預覽
Busy交易/寫者持有中，不並行執行破壞性操作
GenerationNotReady可存草稿，列缺決策，不生成
StorageFailure普通可回復IO失敗；原有效內容保持
PartialProjectCreated只有新專案已建立部分產物，保留草稿並列殘留；不綁成成功
RecoveryRequired回復本身失敗或耐久不確定：保留版本與journal、停止破壞性操作，不聲稱原狀/PASS
NoUndo無歷史或session已關閉，不改狀態

RecoveryRequired不是完成，也不能作「已完整回復」的證據。正常可注入失敗必須恢復原有效內容；若底層回復也失敗，必須保存preimage/紀錄並封鎖後續破壞性操作。OS鎖保護合作的產品寫者，不宣稱對任意外部程序有全域CAS。
