4. Native canonicalization／Port

WizardNativePort: Send + Sync; application-local output port in src-tauri/src/project_wizard_native.rs; never exposed to domain/HOST/JS

  1. Windows local fixed-drive directories only in this S3 slice. Reject UNC, device paths, drive-relative paths, ADS, embedded NUL, dot/dotdot components and non-directory selection. Non-Windows returns UnsupportedPlatform before mutation; no silent lexical fallback.
  2. At picker return inspect each component from drive root using CreateFileW with FILE_FLAG_BACKUP_SEMANTICS|FILE_FLAG_OPEN_REPARSE_POINT and FILE_READ_ATTRIBUTES, FILE_SHARE_READ|FILE_SHARE_WRITE (no FILE_SHARE_DELETE). GetFileInformationByHandleEx FileAttributeTagInfo rejects every reparse component, including junctions/symlinks. Keep component handle chain until selection retired so cooperating rename/delete is blocked; failure to open/hold any component rejects the selection.
  3. GetFinalPathNameByHandleW with FILE_NAME_NORMALIZED|VOLUME_NAME_DOS supplies final absolute path. GetLongPathNameW supplies expanded long spelling. Compare input absolute component spelling against expanded spelling after removing only extended DOS prefix and case differences using CompareStringOrdinal(ignoreCase=true). Different non-case spelling rejects AliasRejected, including 8.3 alias. Never infer long-name expansion by deleting tilde or lexical casefold.
  4. GetFileInformationByHandleEx FileIdInfo supplies volume serial/file-id. Reject if queried component identity or directory/reparse attributes change during capture. Record canonical final root and identity privately; JS display path is inert.
  5. Before reserve and immediately before passing canonical path to S2, revalidate held handle chain and reopen the named path with same flags, compare native identity and final path; reject LocationChanged before invoking S2 if different. Keep held chain through S2 transaction, release on terminal request/cancel once no capture owns it.
  6. IO remains the authority for exclusive child create, CAS, rollback and target alias checks. This native prevalidation does not claim universal filesystem CAS against arbitrary external writers or completion of outstanding IO Windows11/reparse/8.3 gates.
  7. RAII closes handles on every error/cancel/shutdown. Capacity rejection never leaks handles. Do not hold HostState/AppState locks across dialog/native inspection/IO; install only after rechecking caller generation.
