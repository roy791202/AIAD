架構與邊界提案

A1_context
作者→生成預覽→明確確認→受管版本產物；無AI/Git/plugin執行。
A2_hexagonal
UI/Test → Tauri/DispatchHost → HOST generation usecase → WORK pure plan; HOST → existing FileCommitPort + proposed artifact-store Port ← filesystem adapter.
A3_dependency
M01 immutable ProjectDefinition → M02 pure GenerationDecision；M03 consumes activated generation descriptor later；WORK不依賴HOST/Adapter/FS。
A4_responsibility
WORK決策與計畫；HOST驗證approval來源/新鮮度、渲染與交易協調；adapter受管實體產物。
A5_input_ports
既有提案ListTemplate/PrepareGeneration/ConfirmGeneration，精確DTO不在此默認批准。
A6_output_ports
既有FileCommit處理單一啟用描述檔；候選GenerationArtifactStore能力：獨佔建立版本、寫入受管產物、完整性驗證、唯讀存取。簽章待精確提案。
A7_driving_adapters
Vanilla UI及測試consumer；本輪不接入。
A8_driven_adapters
Windows filesystem及本機只讀模板；不下載、不執行模板。
A9_direction
UI→Command→DispatchHost→HOST→WORK/Ports←Adapters；禁止UI直呼FS。
A10_state_ownership
ProjectDefinition仍由M01/WORK持有；GenerationPlan為不可變派生值；啟用描述檔只表達已生成版本，不能回寫成另一個專案SSOT。
A11_mutation
只有核准HOST生成用例可寫其受管版本與單一描述檔；不修改來源模板、未受管檔、原ESS或既有文件Undo。
A12_transaction
exclusive prepare inactive version → render both trees → verify all bytes/hashes → recheck definition/template/approval/base descriptor binding → single-file descriptor commit；此前失敗不切換可見版本。
A13_external_boundary
任何網路/外部writer/未知檔路徑不取得隱含覆寫權；兩骨架完成不等同編譯或功能可用。
A14_forbidden
不得把write_atomic迴圈叫多檔交易；不得自動刪未知版本；不得利用生成改文件Undo或M07快照政策。
