F01 六步新建與草稿

M01｜已確認（局部提案依內文標示）

使用情境
作者尚未決定框架，先保存需求與交付方向，稍後續填。
操作流程
開新建→六步填寫／返回→保存未完成定義或預覽建立→查看實際產物與未決項。
資料影響
確認：保存專案定義草稿。建議：返回不清值，重開回上次已保存步驟；不同交付目標獨立記錄。
狀態
空白／編輯中／草稿已保存／有待決策／建立中／建立成功／失敗。
失敗處理
確認：同名／非空目錄不覆寫。建議：權限或空間錯誤保留表單，列出本次產物；只清理能證明本次新增的檔案，不刪既有內容。
邊界
草稿可缺技術；生成不得以草稿值冒充已批准。建議：只必填名稱與位置，目的及技術可暫定。
驗收條件
AC01：六步可保存重開；生成被阻擋時仍可保存；衝突的既有目錄逐位元不變。
UI schema摘要
六步導覽、欄位標籤、預覽完整路徑、返回／保存草稿／下一步／建立；建議錯誤摘要定位欄位，鍵盤可操作。

F03 架構與程式/UI雙骨架

M02｜已確認（局部提案依內文標示）

使用情境
必要決策齊備的專案產生可檢查骨架；尚未齊備者只保存定義。
操作流程
確認定義→檢查架構／契約／生成條件→預覽模組、介面、檔案及未實作標記→確認生成或退回草稿。
資料影響

F05 ESS編輯、正式保存與專案切換

M04｜已確認（局部提案依內文標示）

使用情境
作者修改場景後保存；關閉或切換前選保存／不保存／取消。
操作流程
新建或開啟→編輯→保存／另存→關閉重開；有dirty時先處理三種選擇。
資料影響
確認：保存成功才更新正式基準；保存失敗保留模型與原有效檔。建議：開啟時先驗證再替換目前文件；無變更無dirty提示。
狀態
未保存新文件／已保存／已修改／保存中／保存失敗／已關閉。
失敗處理
保存失敗留在原文件並顯示原因；不保存只捨本次修改，不清復原快照；取消不離開。
邊界
正式保存不改快照基準。多文件產品模型未定前，不宣稱關閉／切換有跨文件原子交易。
驗收條件
AC05：重開等於成功保存內容；失敗保留原檔與dirty；保存未成功不關閉／切換；A/B內容隔離。
UI schema摘要
文件名／位置／修改標記；保存／另存；關閉、切換、退出的保存／不保存／取消對話框；錯誤持續可見。

資料影響

待預覽／缺依賴／輸出中／完成／取消／失敗。
失敗處理
建議：必要內部素材缺失阻擋完整封裝；輸出失敗或取消不破壞專案，只清本次不完整產物；既有目的檔另行確認取代。
邊界
新建不自動輸出；.ess不偷換為BIN；單獨ESS依賴如何攜帶見架構門檻G01。BIN不是可執行授權。
驗收條件
AC07：只有明確操作才輸出；來源hash不變；內容清單與實際一致；取消不留下被誤認為成功的包。
UI schema摘要

資料影響
確認：來源不變、不執行內容。建議：新專案有新ID並保留來源追溯；只在選定目錄寫入，先在隔離區準備。

失敗處理

整包還原新專案不是單文件合併，也不附跨文件Undo；目錄部分失敗精確清理需G02批准。
驗收條件
AC08：損毀、未知版本、路徑穿越不改目標；副本不依賴作者絕對路徑；待綁定內容可保存但相關生成被阻擋。
UI schema摘要
包資訊、版本、目標、內容與素材完整性、外部依賴；建立副本／合併入口分開；無隱藏執行。

F09 單文件合併與身分衝突

使用情境
作者從BIN選一份文件逐項採用內容，保留本機其他文件不變。
操作流程
選單一目標→預覽增改刪／素材／衝突→逐項選擇→檢查引用及目標版本→確認→整次套用。
資料影響
一份目標文件加必要素材／引用；新身分與引用調整須先預覽確認。建議：方案綁定目標revision及素材版本，過期重新預覽。
狀態
比較中／待選擇／ID衝突／待綁定／可套用／過期／套用成功／完整回復。
失敗處理
跨文件前置條件不滿足即阻擋；來源不明ID略過或另副本；取消／失敗完整回復，不留Undo；缺基準不自動合併。
邊界
不動其他文件；採用刪除也須明選。共用素材不得就地替換而影響其他文件，建議建立新內容版本。
驗收條件
AC09：跨文件依賴阻擋；取消與每個注入失敗點回到同一語義狀態；未受影響資料不變；一次成功套用只占一筆Undo。
UI schema摘要
單文件選擇、差異、素材影響、逐項決策、未解析引用、套用與取消；有未解阻擋時說明原因。

F10 清空與複合Undo

M04｜已確認（局部提案依內文標示）

使用情境
使用者清空或合併後以一次Undo回到前一完整文件狀態。
操作流程

資料影響

狀態
可Undo／操作中／Undo中／成功／失敗需保全。
失敗處理
取消不入歷史；部分套用失敗須回復。建議Undo失敗不消耗歷史並保留可回復狀態；此為G02失敗協定一部分。

限目前文件與本次開啟；不含跨文件／關閉重開歷史、焦點／鼠標／播放進度。Redo規格另列建議，不當已批准。

F11 定期復原快照

M07｜已確認（局部提案依內文標示）

使用情境
作者編輯未保存內容，定期保留一致的可恢復版本，原磁碟離線仍可復原。
操作流程
60秒檢查→等待當前文件操作穩定→對比成功基準→擷取一致版本→寫新快照及素材→完成後發布索引。
資料影響
正式基準與快照基準獨立；ProjectID/SessionID隔離；首次dirty納入。建議：非阻塞擷取不可變版本R，成功只將基準推至R，期間新變更R+1不被吞掉。
狀態
無變更／待檢查／因交易延後／寫入中／成功／失敗待重試／不可寫警告。
失敗處理
寫入失敗保留上一有效快照與待保存狀態，下一輪重試；不可寫可選替代位置；強制終止僅能恢復已成功快照，不承諾最後60秒未落地內容。
邊界
不重疊保存、不擷取中間狀態、不阻塞UI；快照不同於備份。素材完整性與快照需同版本；保存正式檔不改快照基準。
驗收條件
AC11：虛擬時鐘60秒檢查、無變更零新快照；寫入中再編輯下一輪仍保存；索引前中斷保留舊快照；多session不覆寫。
UI schema摘要
持續可見的復原狀態／最後成功時間／失敗原因／替代位置；不以正式保存成功隱藏快照失敗。

F12 歷史入口、復原與保留

M07｜已確認（局部提案依內文標示）

使用情境
作者在最近檔案找到復原版本，原專案離線仍可另存。
操作流程
歷史選復原版本→預覽時間／位置／素材完整性→開為未保存→保存回原檔或另存新位置。
資料影響
移除歷史紀錄不刪文件／快照；正式保存後保留快照。建議：顯式丟棄／清理另有影響預覽與確認。
狀態
可開啟／原路徑失效／素材缺失／已開為未保存／已另存／待清理。
失敗處理
失效路徑保留並解釋；素材缺失列明限制，不假稱完整恢復；保存失敗保留快照及編輯內容。
邊界
新啟動的Undo歷史從空開始；復原只恢復內容。未處理快照永久保留是尚未批准建議，見D01。
驗收條件
AC12：移動免安裝目錄不影響復原；唯讀／離線原專案可另存；移除歷史後快照仍存在；正式保存不抹快照。
UI schema摘要
專案名、復原標記、快照時間、原位置、素材完整性；重新定位／可用復原／移除紀錄；清理另入口。

Hexagonal架構與所有權提案

架構狀態：PROPOSED_NOT_APPROVED。以下是責任及Port角色提案，不批准新增類別／服務／trait，不是從程式碼推測的現況；實作前須盤點既有API與批准精確檔案envelope。
Domain：專案定義、文件模型、穩定身分、引用、版本、dirty與不變條件。Application：新建／保存／生成／封裝／匯入／合併／Undo／快照用例與交易協調。
Driving adapters：精靈、主頁、Editor/Viewer、最近檔案及測試。Input ports：各用例命令及查詢，沿用已知 UI → Tauri Command → DispatchHost → domain → Ports 的專案邊界約束，具體路由需現行來源核對。Output ports：Definition/Document/Asset/Recovery儲存、模板來源、archive codec、transaction、clock、preview；均優先重用現有抽象。Driven adapters：Windows檔案、使用者資料區、封裝解碼、時間與受限預覽環境。
權威狀態：專案定義擁有設定/關係；每份文件擁有自己的內容；素材儲存擁有不可變內容版本；Undo與快照只保存可追溯版本。不得用兩個可變模型同時決定同一內容。Mutation只經命令／用例；序列化、FS、Viewer、歷史清單不能直接改Domain。
交易：保存＝準備→驗證→提交正式檔→更新正式基準；單文件合併＝凍結方案→驗證revision/範圍→準備素材與文件→提交→發布一次Undo；失敗完整回復。快照＝穩定擷取→保存內容與必要素材→發布索引→更新快照基準。新專案還原＝隔離區驗證解開→檢查目標→發布新專案，不涉及既有文件Undo。
外部邊界：包及素材是不可信輸入；宿主／網路／SDK／AI／Git不因載入而啟動。禁止Domain依賴UI/Tauri/FS/OS/具體adapter；禁止UI直呼FS/Git/MCP/adapters；禁止交換模組另建文件SSOT；禁止清理繞過引用根。並發：ProjectID/SessionID隔離只防快照覆寫，不授權同一正式檔多程序last-writer-wins；建議偵測版本衝突拒絕過期保存。

跨功能一致性檢查

交界一致規則／建議解法來源
合併 vs 全包還原BIN合併只改單文件；BIN新專案還原可建多文件，但不提供跨文件Undo。REQ-10,12,15

缺引用 vs 拒絕匯入包中宣告應有卻損毀／缺失的內部內容屬完整性錯誤；明確宣告外部依賴缺失才可人為接受待綁定。REQ-13
